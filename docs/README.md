# RcloneKit 设计与开发入口

当前开发版本：**0.1.0-dev.1**，已实现 Mantine 前端与独立模拟接口；尚未接入真实安装、系统服务或挂载。[运行与开发交接](development/0.1.0-dev.1.md)。正式版前不构建安装包或单独测试程序，由 agent 运行源码检查与自动化测试。

需求来源：[规划 rclone GUI 原型](codex://threads/01a1ce63-7f80-7070-9197-fc40c244b6a9)。按后续讨论收敛为卡片主页、设置安装、地址与盘符式连接；后台采用独立系统服务，覆盖早期由 GUI 管理子进程的建议。本聊天进一步确认：主页只显示是否已挂载，操作错误按需反馈，不常驻展示远端健康或上传状态。

2026-11-18 参数策略：优先沿用固定版本官方默认，仅保留有场景依据的项目覆盖；同一 WebDAV 地址兼顾局域网直连与 TCP VPN，首版不做闲时自动卸载。具体边界见[默认值与超时](design/prototype-plan.md#默认值与超时)，后续按[原生测试基线](design/verification.md#默认参数与移动场景测试基线)逐项比较，尚无实机性能或功耗结论。

参考项目固定为 [mpvkit / 5c03d9e](https://github.com/Leovikii/mpvkit/tree/5c03d9e928a8a592621d43043d2ebc11091004c8)，核对日期 2026-11-12。只继承适用设计规则，不继承其发布授权、历史测试结论或 MPV 专属行为。
