## UI 工程必须覆盖

| 类别 | 验收条件 |
| --- | --- |
| 尺寸 | 480×600、760×760、960×800；预览另测 320 宽回流；无横向溢出、操作遮挡或长地址裁切 |
| 可读性 | 中英文、200% 文本、浅深色、高对比；按钮不裁中文或英文下降字形 |
| 输入 | 空地址、非 HTTP(S)、带 URL 凭据、HTTP 风险提示、已占用盘符、无可用盘符；原生校验与 Rust 再校验 |
| 编辑 | 取消不改已保存配置；失败保留输入；密码不回显，留空不误清空；需断开后编辑 |
| 键盘 | Tab 顺序、Enter 提交、Space 复选、菜单方向键、Esc、焦点锁与回焦；删除默认聚焦取消 |
| 状态 | 卡片仅已挂载/未挂载，操作时临时文案；组件安装、重启和错误仅在对应流程反馈 |
| 并发 | 同一卡片重复点击不启动第二实例；操作一张卡片不锁住整页；安装任务串行且切页不丢任务 |
| 反馈 | 已挂载不暗示远端健康；查询失败不误判未挂载；仅在操作失败或无法安全断开时提示上传等原因 |
| 动效 | 正常与 reduce、快速切页、不重播当前页、草稿保留、滚动位置和弹窗回焦 |

## 原生功能必须覆盖

| 类别 | 必测失败条件 |
| --- | --- |
| 系统安装 | WinGet 缺失、包查询失败、取消 UAC、安装器失败或需重启、仅一组件成功、WinFsp 驱动就绪 |
| 服务权限 | 非管理员 GUI、首次提权、服务程序/配置不可被普通用户替换、跨账户凭据、服务登记归属 |
| 多用户 | 标准用户与提权进程盘符可见性、重启前后、其他用户无权访问远端与凭据 |
| 网络 | DNS 失败、拒绝连接、TLS 错误、服务器不响应、缓慢持续传输、断网及恢复 |
| 断开 | 通过官方机制实测打开文件、待上传、上传失败、检查后出现新写入及正常停止超时。官方能力不足时延期 |
| 数据 | 保存/注册部分失败恢复、实例重发现、盘符竞争、缓存压力、应用退出/系统关机期间写入 |
| 原生 UI | Mica 回退、Windows DPI、屏幕阅读器、系统减少动画；Linux 接入时另测实际桌面与装饰 |

未做实机测试前，不承诺超时数值已经优化、零卡顿、凭据方案可用或上传停止绝对安全。所有系统写入与删除测试在隔离环境执行，不能改开发者真实服务、配置和远端文件。

## 默认参数与移动场景测试基线

首轮使用 WinGet 安装的官方组件及[默认选项](prototype-plan.md#默认值与超时)。下列项目待实机验收。

- 记录 Windows、rclone、WinFsp、WebDAV 服务端与 VPN 软件/传输协议版本，以及脱敏后的有效参数（含继承的默认值和显式覆盖）；升级组件时复核默认值变化。
- 同一 WebDAV 地址分别测试局域网与 TCP VPN；记录延迟、丢包和吞吐条件，覆盖目录浏览、小文件编辑、大文件连续/随机读取及上传，区分冷缓存与热缓存。
- 覆盖 VPN 断开/恢复、局域网与 VPN 路径切换、睡眠/唤醒；核对挂载身份、打开文件、缓存与待上传恢复，不把仍已挂载当成远端已恢复。
- 在相同电源模式、亮度和后台负载下重复比较：VPN 保持连接但未挂载、已挂载空闲、实际读写。记录 GUI 开关状态、CPU、唤醒、磁盘/网络活动及可用的整机功耗/电池耗电数据；单凭内存占用或一次 CPU 采样不判定省电。
- 只有基线出现可复现问题才覆盖参数；每次只改变一个参数，在相同条件下对照，记录改善、等待时间/空间/一致性代价与回退方式。必要时再评估自动卸载，首版不为此增加功能或独立测试程序。
