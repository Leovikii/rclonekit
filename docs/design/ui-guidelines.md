# RcloneKit 界面规范

状态：设计基线，2026-11-12；已实现 Mantine 前端开发版，尚未完成原生实现或验收，见[开发交接](../development/0.1.0-dev.1.md)。

## 参考与适用范围

以 MpvKit 的 [WinUI 3 / Mantine 界面规范](https://github.com/Leovikii/mpvkit/blob/5c03d9e928a8a592621d43043d2ebc11091004c8/docs/design/ui-guidelines.md)、[前端规范](https://github.com/Leovikii/mpvkit/blob/5c03d9e928a8a592621d43043d2ebc11091004c8/docs/v0.1.0/frontend.md)、[主题色阶](https://github.com/Leovikii/mpvkit/blob/5c03d9e928a8a592621d43043d2ebc11091004c8/src/brand.ts)为依据。采用其基于 WinUI 3 / Fluent 的设计原则，以 Mantine 实现；尺寸是项目选择，不是微软强制要求。

本项目的范围、状态和错误文案以[原型方案](prototype-plan.md)为准。MpvKit 的媒体预设、播放器图标、配置覆盖与完整卸载流程不适用于网络驱动器。

## 视觉与布局

| 项目 | RcloneKit 基线 | 与 MpvKit 的关系 |
| --- | --- | --- |
| 导航 | 主页与设置两页，无侧栏；主页右上设置，设置左上返回 | 沿用 |
| 窗口客户区 | 建议默认 760×760，最小 480×600 | 为双列卡片加宽，需原型验证 |
| 网格 | 客户区宽度达到 720 时双列，否则单列；最多两列，新增卡片始终最后 | 本项目新增 |
| 页面 | 左对齐，24 内边距；宽度不超过 520 时水平 16；内容最大宽度 960 | 沿用留白，扩展内容宽度 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32；卡片间距 16，内边距 16 | 沿用 |
| 字体 | Windows：Segoe UI Variable → Segoe UI → Microsoft YaHei UI；Linux：system-ui → Noto Sans CJK SC | 沿用平台字体策略 |
| 字号与字重 | 页标题 28/600，分组和卡片标题 14/600，正文 14/400，辅助信息 12/400 | 沿用；使用 rem 适应文本缩放 |
| 控件 | 输入和图标动作约 32；文字按钮至少 36 高，可随文案增高 | 沿用；触屏扩大有效命中区 |
| 圆角 | 控件与卡片 4，弹层 8；页面不套大圆角底板 | 沿用 |
| 背景 | 浅色基底 #F3F3F3、卡片 #FFFFFF；深色基底 #202020、卡片 #2D2D2D；细中性边框 | 沿用 |
| 强调色 | 固定 #A84BD6，主动作使用较深色阶确保文字对比；不开放取色或配色设置 | 沿用色系；独立图标后续设计 |
| 状态色 | 文本配合图标表达已挂载/未挂载；不整卡染色 | 沿用语义原则，收敛为管理状态 |
| 材质 | Windows 保留系统标题栏，Mica 仅作用于窗口基底；不可用时实色回退 | 沿用；浏览器仅模拟实色 |
| Linux 装饰 | 后续遵循目标桌面系统装饰；不复制 Windows 标题栏按钮 | 沿用系统优先原则，目标发行版待定 |

无常驻卡片阴影、渐变横幅、玻璃卡片、大面积紫色背景或装饰性仪表盘。新增卡片只使用低对比边框和“添加网络驱动器”，不在标题栏再重复一个新增按钮。

## 卡片与表单

- 卡片阅读顺序：盘符与主机名 → 状态 → 地址 → 必要提示 → 操作。标题不要求额外命名；完整地址可换行，禁止仅省略而无查看方式。
- 状态文字不能只靠颜色。只显示“已挂载/未挂载”，操作期间短暂显示“正在挂载/正在断开”；不常驻展示远端健康、上传队列或多重徽章。
- 已挂载显示“打开、断开”，未挂载显示“连接”；操作失败在卡片内提示并提供相关重试，编辑和删除位于更多菜单。
- 整卡不是隐形点击区；新增卡片本身是一个语义按钮。键盘可达所有动作，不依赖悬停显示关键操作。
- 新增与编辑复用一个表单。常用字段为 WebDAV 地址、盘符；身份验证与高级选项按需展开。不出现只有 WebDAV 一个选项的类型选择器。
- 表单动作右侧以外不放冗余保存入口。对话框执行按钮在左、取消在右；卡片操作靠右。错误在相关字段或卡片内展示，不能仅发一闪而过的通知。
- 长地址、错误和中文按钮可换行；卡片按内容增高。窄窗单列，卡片动作换行，不压小字号或裁切控件。

## Mantine 实施约束

正式前端采用 React + TypeScript + Mantine core/hooks；以 MpvKit 当前 9.7.3 为拟用基线，创建工程时核对可用版本与声明并提交锁文件。不得把聊天内示意样式直接当作生产控件实现。

| 用途 | 组件 |
| --- | --- |
| 布局、卡片 | Group / Stack / Paper；自有 CSS 仅负责网格、留白、换行 |
| 设置、返回、更多 | ActionIcon + Tooltip / Menu；图标可访问名称齐全 |
| 常用表单 | TextInput / PasswordInput / NativeSelect / Checkbox / Button |
| 高级选项 | Accordion；Control 内不嵌按钮 |
| 错误、任务、弹窗 | Alert / Loader / Progress / Modal |
| 滚动 | 页面 ScrollArea；长弹窗 ScrollArea.Autosize，避免双重滚动 |

一个 MantineProvider，以 createTheme 集中管理主题；先导入库样式再导入布局样式。只用公开 props、主题及 Styles API，不依赖内部结构，不手写菜单键盘、焦点锁、滚动条或折叠动画。不另建表单引擎、控件包装体系或动画依赖。

工程实施前阅读 [Mantine 官方 LLM 索引](https://mantine.dev/llms.txt)及实际使用组件的 API 正文，再核对固定版本的类型声明；文档链接不等于已完成版本验证。打包资源全部本地提供，无运行时 CDN 或远程字体。

## 弹窗、反馈与动效

- 安装的确认、执行、结果与重试在同一 Modal；只安装缺失项，成功以重新检测为准。UAC 和包管理器交互保留，不代答。
- 下载有真实总量才显示百分比；未知阶段使用 Loader 和状态文字。按钮不承载进度，下载完成不能显示安装完成。
- 新增连接无需额外测试按钮或重复确认；表单已显示的地址、目标和只读选择构成操作预览。涉及系统授权时交给原生 UAC；首版不显示开机连接开关。
- 删除配置需显示具体目标和保留数据的说明；默认焦点落在取消。正在使用或状态未知时不能直接删除。
- Modal 保留焦点锁、Esc、回焦；任务期间是否能取消由操作能力决定，不假装可以中止系统安装。触发器消失时回焦到新增卡片或可用导航。
- 页面切换使用 Mantine 内置 fade-up：200ms/ease-out；Accordion 180ms；Modal fade 160/120ms；Tooltip fade 120/90ms。只动画新页，不动画整个窗口或每次状态刷新。
- 开启 respectReducedMotion，并补 CSS 减少动态效果回退；不加产品动画开关。错误即时出现，不能等待动画结束。
- 成功与状态变化使用 polite live region，真实错误使用 alert。保留可见 label、焦点轮廓、原生键盘语义。

## 验收

按[验收记录](verification.md)检查布局、键盘、200% 文本、双语、主题、高对比与减少动态效果。真实 Mica、Windows DPI、系统动画映射、屏幕阅读器和 Linux 窗口装饰必须原生验证，不能由浏览器截图代替。
