# 0.1.0-dev.1 开发交接

日期：2026-11-12。首个开发版本，范围是正式组件实现的前端与可替换模拟接口。

## 当前实现

- React + TypeScript + Mantine 9.7.3，Vite 源码运行；使用固定依赖及 pnpm 锁文件，无 CDN 和远程字体。
- 主页/设置两页，无侧栏。卡片只常驻显示已挂载/未挂载；错误就地反馈，操作时临时显示进度文字。
- WebDAV 新增、编辑、连接、断开和删除交互；新增卡片始终最后。编辑和删除先断开，删除默认聚焦取消。
- 只读为唯一高级选项；身份验证折叠，HTTP 提示未加密；失败保留输入，关闭表单清除密码。
- 组件检测、安装、部分失败、需重启、状态读取失败、网络错误和待上传阻止断开的模拟分支。
- 中英切换、系统/浅色/深色主题。仅语言和主题写入 localStorage；示例配置在内存，密码不写入存储或快照。
- 每个挂载独立互斥、重复操作阻止，其他卡片仍可操作。读取失败不误判为未挂载。

页面始终明确标识模拟模式。安装/打开磁盘均不执行真实系统操作；模拟安全停止不能视为已验证 rclone 安全停止。

## 代码边界

| 文件 | 职责 |
| --- | --- |
| [model.ts](../../src/model.ts) | 带 `kind: webdav` 的连接模型、独立挂载 ID/目标、表单校验与候选默认值 |
| [api.ts](../../src/api.ts) | 页面使用的业务接口与能力快照；下一阶段由桌面 IPC 实现 |
| [demo.ts](../../src/demo.ts) | 独立内存模拟，供开发与失败场景测试；不调用网络或 OS |
| [App.tsx](../../src/App.tsx) / [MountEditor.tsx](../../src/MountEditor.tsx) | 页面、卡片、弹窗与表单展示 |
| [i18n.ts](../../src/i18n.ts) / [theme.ts](../../src/theme.ts) | 双语短文案、脱敏错误映射、统一 Mantine 主题 |
| [测试](../../tests) | 模型/模拟边界测试及真实浏览器交互检查 |

新增连接类型时扩展连接判别联合与对应表单/校验；挂载生命周期接口和卡片无需按协议复制。新增 Linux 时扩展挂载目标与能力结果。当前不增加插件注册表、通用表单引擎或平台实现占位代码。

`mountDefaults` 仅记录项目选择（网络盘模式、full 缓存、10 GiB 清理目标候选与关闭开机连接），不复制官方默认参数。2026-11-18 已移除此前 10s 连接、30s I/O 空闲与 2 次底层重试的覆盖；未来后端省略这些参数以沿用固定版本默认。当前没有真实 rclone 执行路径，因此不能宣称参数已经启用或经过性能验证。

参数策略以[原型方案](../design/prototype-plan.md#默认值与超时)为准；缓存保留、清理、目录缓存、写回、预读与并发优先使用官方默认。局域网和 TCP VPN 共用同一地址，首版不实现闲时自动卸载/按需自动挂载。后续先按[测试基线](../design/verification.md#默认参数与移动场景测试基线)记录实际参数、网络恢复及功耗，再决定是否需要覆盖默认。

## 运行与检查

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm test:ui
```

`test:ui` 先编译网页资源，再启动仅监听回环的临时预览服务器，用无头浏览器测试实际构建页面。Windows 使用已安装的 Edge；其他平台需提供 Playwright Chromium。临时服务器由测试进程收尾。

网页构建只生成 `dist` 资源，不构建安装包或独立测试程序。根据用户本轮要求，正式版本前不打包分发；不创建 CI、发布或签名流程。

本轮 `pnpm check` 已通过：类型检查、13 项模型/模拟接口测试、网页构建与 13 项浏览器测试。视觉检查与原生边界详见[验收记录](../design/verification.md)。

浏览器测试的截图/失败诊断在忽略的 `test-results` 中。测试只填虚构凭据；Playwright 失败 trace 可能记录表单输入，不得用真实凭据运行这些测试或共享 trace。

## 下一阶段

按[原型方案](../design/prototype-plan.md)继续：Tauri/Rust 工程与只读组件/盘符检测 → 隔离 Windows 环境验证受保护程序路径、服务账户、ACL、凭据与本地认证 RC → 真实挂载、安全停止与安装。当前机器未找到 Rust/MSVC 工具链，本次未安装它们，也没有创建未经编译验证的 Rust 占位业务代码。

真实后端必须再次校验所有字段；前端校验不能代替信任边界。服务状态与远端健康仍分开处理，用户只看管理状态。开机连接、凭据保存开关、自定义缓存/超时、其他协议与 Linux 的实现留到后续版本。
