# 0.1.0-dev.2 Windows 桌面开发交接

2026-11-19。接续 [0.1.0-dev.1 网页前端](0.1.0-dev.1.md)，接入 Tauri 2 与 Windows 平台。

Windows 桌面沿用 Mantine 两页、系统／浅色／深色与双语偏好。设置通过 WinGet 查询并安装缺失的 rclone 和 WinFsp。主页使用 Windows 盘符查询结果，通过标准 WebDAV 预检后可保存、编辑和删除本地配置。网页继续提供独立模拟流程。当前实现、组件维护边界与后续验收见 [Windows 开发记录](windows-alpha.md)。

## 从源码运行

网页需要 Node.js 24 或更新版本和 pnpm 11.25.0。Windows 桌面开发还需要 Rust 1.99 或更新版本的 MSVC 工具链、Visual Studio C++ 生成工具、Windows SDK 和 WebView2 Runtime。组件检测与安装使用 Windows 应用安装程序提供的 WinGet。前端与 Rust 开发依赖分别由 [pnpm 锁文件](../../pnpm-lock.yaml) 和 [Cargo 锁文件](../../src-tauri/Cargo.lock) 固定。

```sh
pnpm install --frozen-lockfile
pnpm dev:desktop
```

运行 `pnpm dev` 可单独打开网页模拟版。桌面开发窗口与网页预览共用回环端口 1420，分别启动。前端检查使用 `pnpm check`，Rust 检查使用 `cargo test --locked --manifest-path src-tauri/Cargo.toml`。桌面构建配置关闭安装包输出。

## IPC

- [前端适配器](../../src/desktop.ts) 暴露环境快照、组件安装和配置管理。
- [Windows 平台模块](../../src-tauri/src/platform/windows.rs) 负责 WinGet、可用盘符及只读服务查询。
- [配置与预检](../../src-tauri/src/mounts.rs) 保存应用自己的配置，通过 [WebDAV 预检](../../src-tauri/src/webdav.rs) 校验地址和凭据。
