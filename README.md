# RcloneKit

轻量的 rclone 安装与网络驱动器管理界面。

当前版本 **0.1.0-dev.1** 是 WebDAV 交互开发版：包含挂载卡片、新增/编辑表单、设置、简体中文/English 和系统/浅色/深色主题。

**当前使用模拟数据，不执行真实安装、挂载或系统服务操作。** 顶部可切换示例场景；刷新页面会重置示例挂载，语言与主题保留。密码不会保存。

## 从源码运行

需要 Node.js 24 或更新版本，以及 pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 [本地开发页面](http://127.0.0.1:1420)。目前不提供安装包。

## 使用

在主页末尾选择“添加网络驱动器”，填写 WebDAV 地址与盘符；身份验证按需填写，高级选项仅提供“只读”。已有卡片可连接、断开，或从更多菜单编辑、删除配置。
